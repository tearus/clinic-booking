# Clinic API

REST API для сайта медицинской клиники. Пациент записывается на приём без регистрации (ФИО и телефон), а подтверждает или отменяет запись по персональной ссылке.

**Стек:** NestJS · TypeScript · PostgreSQL · Prisma · Swagger · Docker Compose

## Как это работает

1. Клиент выбирает врача и свободный слот.
2. `POST /appointments` атомарно занимает слот и возвращает персональный токен.
3. За 48 часов до визита клиенту уходит ссылка `/appointments/<token>`, где можно подтвердить или отменить запись.
4. Не подтвердил за 24 часа до визита: запись аннулируется, слот освобождается.

Статусы записи: `ACTIVE` → `CONFIRMED` / `CANCELLED` / `EXPIRED`.

## Запуск

Нужны Node.js 22+ и Docker.

```bash
cp .env.example .env
docker compose up -d
npm install
npx prisma migrate deploy
npx prisma generate
npm run start:dev
```

Swagger: http://localhost:3000/docs

## Эндпоинты

| Метод | Адрес | Описание |
|---|---|---|
| GET | `/doctors`, `/doctors/:id` | врачи |
| GET | `/specialty` | специальности |
| GET | `/slots?doctorId&date&onlyFree` | слоты с фильтрами |
| POST | `/appointments` | записаться |
| GET | `/appointments/:token` | запись по ссылке |
| POST | `/appointments/:token/confirm` | подтвердить |
| POST | `/appointments/:token/cancel` | отменить |

Создание и изменение врачей, специальностей и слотов пока открыто без авторизации.
